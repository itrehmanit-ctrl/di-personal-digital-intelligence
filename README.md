# DI — Personal Digital Intelligence

Public project page for **DI** (local-first personal assistant).

## Full app (on your PC)

```bash
cd di && ./start.sh
# → http://127.0.0.1:8000
```

## Features

- Local Ollama chat
- Auth, notes, audit logs
- Allowlisted passive security scans
- Safe automation (confirm-with-user)
- Dangerous tools hard-disabled

This GitHub site is informational. Full backend requires local Python + Ollama.
